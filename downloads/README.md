# コマ地図表示ページ UI共有版

[koma-page-ui.zip をダウンロード](https://github.com/ogawa333/miyagawacode/raw/refs/heads/share/koma-page-ui/downloads/koma-page-ui.zip)

1. ZIPを「すべて展開」します。
2. 展開先の `koma-ui-share/koma-ui.html` をブラウザで開きます。

地図の図形だけでなく、キャラクター・コマ番号・前後ボタン・コース一覧・設定を含む、表示ページ全体のUIです。三崎39コマと城ヶ島29コマ、デザイン切り替え、iPhone 16想定の393×852表示枠を含みます。

Node.js・Codespaces・ローカルサーバー・APIキーは不要です。HTMLに画像・スタイル・プログラムを同梱しています。コース作成・運営者機能・DB保存・参加者受付は含みません。

素材の出典と条件はZIP内の「素材の出典.txt」を参照してください。

この専用ブランチはファイル受け渡し用です。mainへのマージは行いません。
