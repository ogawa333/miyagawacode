# 参加者の画面デザイン切替

2026-11-12、ユーザーの依頼に基づき「地図の見方と設定」に3案のデザイン選択を追加。

- 海：淡い水色、波の線画、青緑の丸いボタン。
- マグロ：港の紺、マグロの線画、朱色のボタンと生成りの地図。
- サイトの世界観：既存サイトに合わせたアイボリー、青、朱色。初期値。

参加者の公開コースのコマ画面に適用する。選択は即時反映し、ブラウザのlocalStorageの `miura-walk-design-v1` へ保存する。コースをまたいで共通の設定とし、保存できない環境でも画面内の切替を利用できる。不明な保存値は初期値を使う。

デザイン案は `app/walk-design-selector.tsx` の一覧と `app/walk-designs.css` のスコープ付きスタイルで追加できる。通常コマと周辺参照図へ同じ配色を適用。道路の位置・接続・進行方向・コマ順序・チェックポイントの案内内容は変更せず、進行矢印は青を維持する。

DB・コースの保存形式・公開状態・参加開始記録に変更なし。追加依存・画像取得・外部APIなし。
